# Task 2 — Backend & Infrastructure Deliverables

This directory contains the technical documentation, infrastructure evaluations, and verification artifacts for the enquiry management system.

## Deliverables

1. **Architecture & Infrastructure Report (`Task-2-Report.md` / `Task-2-Report.pdf`):**
   - Website technologies, hosting infrastructure, and backend integrations.
   - Database, security, and performance recommendations.
   - Internal IT, business email authentication (SPF, DKIM, DMARC), and operational tooling.
   - Database-backed enquiry implementation and administrative query interface.
   - Prioritized implementation roadmap and risk register.

2. **Verification & Testing (`Verification.md`):**
   - Automated backend unit and integration test results.
   - HTTP smoke tests and API interaction logs.
   - Browser verification evidence and screenshots.

## Supporting Evidence

- `Hosted-Evidence.json`: Deployed API interaction evidence.
- `Browser-Evidence.json`: Browser validation checkpoints.
- `Demo-Evidence.json`: Local HTTP query response and sample database record.
- `Demo-Enquiries.sqlite`: Fictional database snapshot for local demonstration.
- `Demo-Queries.sql`: SQL queries demonstrating search and analytics.
- `Public-Technical-Observations.json`: Public HTTP headers, DNS records, and asset fingerprints.
- Screenshots (`Saved-Enquiry.jpg`, `Enquiry-Desk.jpg`, `Enquiry-Desk-Mobile.jpg`).
